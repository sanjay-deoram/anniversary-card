# anniversary-card

A Japan-themed anniversary card for Bee: photos on a clothesline and a card in the middle that opens when you tap it.

```sh
npm install
npm run dev      # local preview
npm run build    # static site in dist/
```

- **The letter, captions and photo order** are in `src/content.js`.
- Photos live in `public/photos/` (`name.jpg` full size, `name-sm.jpg` clothesline size). The video is in `public/video/`.
